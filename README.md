SIW Products 🛍️
A dynamic and modern web application built with Java Spring Boot for managing a product catalog. This project allows users to browse items, search for products, and leave comments, while administrators have full control over the catalog's content.

✨ Key Features
Product Catalog: A clean and responsive interface to display all available products.

Advanced Search: Users can search for products by name or filter them by type. 🕵️‍♂️

User Authentication: A complete registration and login system built with Spring Security.

Two-Role System:

👤 Users: Can browse products, post comments, and edit/delete their own comments.

🛡️ Admins: Have access to a dedicated admin area to perform full CRUD operations (Create, Read, Update, Delete) on products, manage types, and oversee all user comments.

Dynamic Relationships: Admins can link products together as "similar products." 🔗

🛠️ Tech Stack
Backend: Java, Spring Boot (Web, Data JPA, Security)

Frontend: Thymeleaf, HTML, CSS, Bootstrap

Database: PostgreSQL

Build: Maven
